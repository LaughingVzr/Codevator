# Codevator 0.1.0

The first preview release brings local Git projects, worktrees, and coding conversations together in a native Mac app.

- Browse several projects and their worktrees in one sidebar. Create a worktree from an existing branch or a new branch.
- Open Codex and Claude Code in separate terminal tabs. Conversations keep running when you switch tabs or worktrees.
- See when a conversation finishes on its tab and in the sidebar, with optional macOS notifications.

**Requirements:** macOS 14 or later and Git. Install Codex or Claude Code separately to use it in Codevator.

**Download:** `Codevator-0.1.0-macOS.zip` contains the app for Apple silicon and Intel Macs. Extract it and move Codevator to Applications. The app is **unsigned and not notarized**; macOS may require you to review it before opening.

SHA-256: `65bb16adc8a22b3390b4567eb856b997c8ed3b58c746a1ac8b604f3b77130270`

This is an early preview. Running conversations and terminal history are not restored after quitting. System Pinyin input has not yet passed stable end-to-end verification in both coding tools.

Validation: 27 automated tests passed, 1 skipped, 0 failed on an Apple silicon Mac. The universal app contains both `arm64` and `x86_64`; it has not been tested on an Intel Mac or on macOS 14.
