# Codevator 0.1.3

This update makes it easier to see where your coding conversations need attention, and adds a regular terminal alongside Codex and Claude Code.

- A green indicator beside a worktree or project shows conversations waiting for a reply. An orange indicator shows replies that finished while you were elsewhere and have not been viewed yet. Both can appear at the same time when a worktree has several tabs.
- Open a **Terminal** tab in any worktree to use your Mac's shell without starting an AI tool. Regular terminal commands do not trigger AI reply indicators or notifications.
- Change terminal text size in **Settings → Terminal**, or use **⌘+**, **⌘−**, and **⌘0**. Open tabs update immediately.
- The English and Chinese READMEs now explain the current workflows and link to the Releases page instead of a fixed download version.

**Requirements:** macOS 14 or later and Git. Install Codex or Claude Code separately if you want to use either tool; the regular terminal needs neither.

**Download:** `Codevator-0.1.3-macOS.dmg` contains a universal app for Apple silicon and Intel Macs. Open the disk image and drag Codevator to Applications. The app is **unsigned and not notarized**; macOS may ask you to review it before opening.
