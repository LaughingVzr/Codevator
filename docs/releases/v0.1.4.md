# Codevator 0.1.4

This update makes conversation status more dependable while you move between projects and worktrees.

- The green running indicator now appears when an AI request is actually waiting for a reply. Opening Codex, submitting an empty line, or changing `/permission` settings no longer leaves a worktree marked as running.
- A completed reply clears the running indicator and keeps the existing unread notification behavior.
- Codex terminal output now receives a final full redraw after fast updates, reducing stray white blocks in text-heavy conversations.

**Requirements:** macOS 14 or later and Git. Install Codex or Claude Code separately if you want to use either tool; the regular terminal needs neither.

**Download:** `Codevator-0.1.4-macOS.dmg` contains a universal app for Apple silicon and Intel Macs. Open the disk image and drag Codevator to Applications. The app is **unsigned and not notarized**; macOS may ask you to review it before opening.

SHA-256: `7d41c2567e0cf12d1d8702ac043c1a11bc1a0c4f0c30cf835eef1270c3ab7227`

Validation: 32 unit tests and 5 macOS UI tests ran on an Apple silicon Mac, with no failures. One unit test and one UI test for Claude Code were skipped because the local Claude CLI was unavailable. The DMG passed checksum verification and contains both `arm64` and `x86_64`. Intel hardware and macOS 14 have not yet been tested directly.
