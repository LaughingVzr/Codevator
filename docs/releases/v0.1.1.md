# Codevator 0.1.1

This preview improves the Codex terminal and makes the project easier to build from source.

- Selected terminal text now goes to the macOS clipboard as plain text, including Chinese text. Pressing ⌘C without a selection leaves the existing clipboard content intact.
- Codex output triggers a full terminal repaint to reduce transient white blocks during text updates. Some rendering artifacts may still appear while output is changing.
- The READMEs now show the app with sample projects and worktrees, and `make build`, `make test`, `make test-ui`, and `make dmg` replace the Ruby project helper.

**Requirements:** macOS 14 or later and Git. Install Codex or Claude Code separately to use it in Codevator.

**Download:** `Codevator-0.1.1-macOS.dmg` contains a universal app for Apple silicon and Intel Macs. Open the disk image and drag Codevator to Applications. The app is **unsigned and not notarized**; macOS may require you to review it before opening.

SHA-256: `875357ddc38ee10d6612ce32928223dbb454f90e86069658a6858dd20390ef2c`

Validation: 27 unit tests and 2 macOS UI tests passed on an Apple silicon Mac. One unit test and one UI test for Claude Code were skipped because the local Claude CLI was unavailable. The universal binary contains both `arm64` and `x86_64`; it has not been tested on an Intel Mac or on macOS 14.
