# Codevator 0.1.2

This patch makes completion alerts more reliable when you leave a coding conversation running in the background.

- Codex's internal title-generation event no longer marks a tab as finished before the actual reply is ready.
- When a Codex or Claude reply finishes in a background tab, Codevator marks it unread and sends a macOS notification with the default sound.
- The new **Settings → Notifications** page shows whether alerts and sounds are allowed, lets you request permission, and links to macOS notification settings.

**Requirements:** macOS 14 or later and Git. Install Codex or Claude Code separately to use it in Codevator.

**Download:** `Codevator-0.1.2-macOS.dmg` contains a universal app for Apple silicon and Intel Macs. Open the disk image and drag Codevator to Applications. The app is **unsigned and not notarized**; macOS may require you to review it before opening.

SHA-256: `7d35c8cec461614e4185b0b7f84838933c1b03f50c10ad01a124a9a6dc842b50`

Validation: 27 unit tests and 2 macOS UI tests passed on an Apple silicon Mac. One unit test and one UI test for Claude Code were skipped because the local Claude CLI was unavailable. The DMG was verified and its app contains both `arm64` and `x86_64`; it has not been tested on an Intel Mac or on macOS 14.

macOS controls whether notification banners and sounds appear. For example, notifications may be paused while the display is shared, depending on your system settings.
